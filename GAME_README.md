# Piknik Kahramanları: Zafer!

Türkçe, 2D mobil macera oyununun ilk oynanabilir sürümüdür.

## Oynanış

- Beş bölüm vardır: Orman Yolu, Nehir Kıyısı, Tepe Yolu, Mağara Geçidi ve Ada Finali.
- Anne, baba ve kız karakterleri arasında geçiş yaparak görevleri çözün.
- Sağa ilerleyin, zıplayın, eşyaları toplayın ve doğru karakterle etkileşime geçin.
- Son bölümde takım çalışması düğmesiyle Ismail’i piknik alanından uzaklaştırın.
- Bölüm ilerlemesi cihazda yerel olarak kaydedilir.

## GitHub üzerinden APK

1. `artifacts/piknik-kahramanlari` klasörünün içeriğini GitHub deposunun köküne yükleyin.
2. Depoda **Actions** sekmesini açın.
3. **Android APK** iş akışını seçip **Run workflow** düğmesine basın.
4. İş akışı tamamlanınca run sayfasındaki **Artifacts** bölümünden APK dosyasını indirin.

İş akışı ayrıca `main` dalına yapılan her push sonrasında çalışır.
